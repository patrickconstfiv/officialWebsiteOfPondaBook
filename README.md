# PondaBook Official Website

Static marketing site for **PondaBook: Renovation Budget**.

## Files

- `index.html`: page structure
- `style.css`: styling and responsive layout
- `script.js`: lightweight scroll and hover effects

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open `Settings` -> `Pages`.
3. Set the source to the branch you want to publish, usually `main`, and the root folder `/`.
4. Save, then wait for GitHub Pages to publish the site.

No build step or extra dependency is required.
